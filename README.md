# OpenKB - KfW Energieberater Knowledge Base

![Lint](https://github.com/vectifyai/engai-rag/workflows/lint/badge.svg)

OpenKB is a structured knowledge base for KfW funding programs and energy consulting, built from document ingestion and maintained as a wiki.

## Quick Start

### Browse with Obsidian (Recommended)

The `wiki/` folder is a fully functional Obsidian vault. Open it in Obsidian for the best browsing experience.

1. Install [Obsidian](https://obsidian.md)
2. Open Obsidian → "Open folder as vault" → select `wiki/`
3. Recommended community plugins:
   - **Dataview** - Query markdown files like a database
   - **Excalidraw** - View and edit diagrams
   - **Graph View** - Visualize connections between concepts

#### Graph View

Press `Ctrl/Cmd + G` to open Graph View. Use it to:
- Explore relationships between KfW programs, technical terms, and sources
- Find related concepts visually
- Identify clusters of related topics (e.g., all heating-related programs)

**Graph View Settings:**
- Show: Outgoing links
- Group by: Folder
- This highlights the structure: `concepts/`, `sources/`, `summaries/`, `explorations/`

#### Dataview Queries

Dataview enables SQL-like queries over your markdown files. Enable it in Obsidian settings → Community plugins.

**Example queries for KfW concepts:**

```dataview
TABLE program, category, funding
FROM "concepts"
WHERE contains(file.name, "kfw")
SORT file.name ASC
```

```dataview
LIST
FROM "concepts"
WHERE contains(tags, "kfw") OR contains(tags, "förderung")
```

```dataview
TABLE
FROM "#kfw-programm"
```

```dataview
TABLE description, source
FROM "concepts"
WHERE contains(file.name, "effizienzhaus") OR contains(file.name, "energieausweis")
```

**Tip:** Add tags like `#kfw-programm`, `#technisch`, `#rechtlich` to concept pages for easier querying.

### Basic File Browsing

If you don't use Obsidian, simply browse the `wiki/` folder in any file manager or text editor. The wiki uses standard Markdown with `[[wikilinks]]` for cross-references.

## Wiki Structure

```
wiki/
├── index.md           # Content catalog with links to all pages
├── log.md             # Operation history (ingests, queries, lints)
├── AGENTS.md          # Schema and rules for the OpenKB compiler
├── concepts/          # Cross-document topic syntheses
├── sources/           # Original document content (ingested)
├── summaries/         # One-page summaries of each source
├── explorations/      # Saved query results and analyses
└── reports/           # Auto-generated health check reports
```

## Contributing

- Do not edit files in `sources/` directly — they are generated by ingestion
- Add new concepts in `concepts/` following the schema in `AGENTS.md`
- Use `[[wikilinks]]` to link related pages
- Keep pages focused on a single topic
- Cite sources using `[Quelle: doc_XXX, S. YY]` format for factual claims
