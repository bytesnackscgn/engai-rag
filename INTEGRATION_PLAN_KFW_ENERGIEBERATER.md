# Integration Plan: KfW/Energieberater Chat-AI-Assistent

## 📋 Projektübersicht

**Ziel:** Erstellung eines Chat-AI-Assistenten für KfW / Energieberater / Sanierungsberater basierend auf OpenKB mit Vectorless RAG

**Kern-Technologien:**
- **Knowledge Base:** [OpenKB](https://github.com/VectifyAI/OpenKB) (basiert auf PageIndex)
- **LLM:** OpenRouter `z-ai/glm-4.7-flash`
- **API-Framework:** FastAPI
- **CLI-Tool:** Eigene Python-CLI für Index-Management
- **Authentifizierung:** API-Key basiert

## 🔄 Indexierungsprozess

### Hybrid-Index Workflow

```
1. SYNC PHASE
   ├─ Liest File List JSON
   ├─ Vergleicht mit index_status.json
   ├─ Identifiziert neue/veränderte Dateien
   └─ Kopiert neu hinzugekommene Dateien nach raw/

2. STATUS PHASE
   ├─ Update index_status.json
   ├─ Markiert neue Dateien als "pending"
   └─ Erhält alte Dateien als "indexed"

3. INDEX PHASE (Hybrid)
   ├─ NEW FILES (< 10% Unterschied):
   │  └─ Incremental Index via OpenKB
   │     └─ markitdown → PageIndex → LLM
   ├─ MODIFIED FILES (> 10% Unterschied):
   │  └─ Full-Index (reset affected wiki pages)
   └─ ALL FILES:
      └─ Aktualisiert wiki/concepts/ synthese

4. VALIDATION PHASE
   ├─ Lint OpenKB Wiki
   ├─ Check Konflikte
   ├─ Check Lücken
   └─ Aktualisiert health_score
```

### CLI Index Command

```bash
# Check current status
engaichat index check

# Sync files from repository
engaichat index sync

# Run hybrid index
engaichat index run

# Force full index (reset cache)
engaichat index force
```

## 🎯 Chat-Features

### 1. Kontext-sensitive Antworten

```python
async def chat_with_context(
    message: str,
    history: List[Dict],
    max_history_turns: int = 5
) -> ChatResponse:
    """
    Chat mit Kontext-Gedächtnis

    - Behält conversation history bei
    - Kontextorientierte Wiki-Abfragen
    - Wiederholungen vermeiden
    """

    # Kontext-Pruning
    if len(history) > max_history_turns:
        history = history[-max_history_turns:]

    # Wiki-Abfrage basierend auf History
    relevant_concepts = retrieve_relevant_concepts(history)

    # System Prompt with Context
    system_prompt = f"""
    Du bist ein erfahrener KfW/Energieberater.
    Die folgenden Wissen sind relevant für unsere Unterhaltung:
    {relevant_concepts}

    Frage: {message}
    """
```

### 2. Quellen-Nachweise

```python
async def chat_with_sources(message: str) -> ChatResponse:
    """
    Chat mit Quellen-Nachweisen
    """
    response = await llm.chat(message)

    # Wiki sources extrahieren
    wiki_sources = openkb.query_sources(message)

    return ChatResponse(
        response=response.text,
        sources=[
            {
                "doc_id": source['doc_id'],
                "title": source['title'],
                "page": source['page'],
                "text": source['text'],
                "confidence": calculate_confidence(source)
            }
            for source in wiki_sources[:5]  # Top 5 Quellen
        ]
    )
```

### 3. Intelligenz-Analysen

```python
async def intelligence_analysis(
    analysis_type: str,
    building_context: Dict,
    energy_profile: Dict
) -> IntelligenceAnalysis:
    """
    Spezialisierte Beratungsanalysen

    Typen:
    - kfw_qualification: KfW-Förderquellen
    - energy_audit: Energieaudit-Empfehlungen
    - renovation_potential: Sanierungspotential
    - cost_benefit: Wirtschaftlichkeit
    """

    system_prompt = f"""
    Du bist ein KfW-Förderberater und Energieexperte.

    Analyse-Typ: {analysis_type}

    Gebäude-Kontext:
    {building_context}

    Energie-Profile:
    {energy_profile}

    Erstelle detaillierte, konkrete Empfehlungen mit:
    - Förderprogramme (KfW-Nummern, Höhe)
    - Dämm-Maße
    - Technologien
    - Wirtschaftlichkeit
    - Quellen
    """

    analysis = await llm.chat(system_prompt)
    return IntelligenceAnalysis(response=analysis)
```

## ✅ Wichtigste Best Practices

### 1. Index-Management
- Automatisiere Sync-Prozess nicht ohne Überprüfung

- API-Keys sicher speichern (.env)

- Logging ohne sensible Daten

- Regelmäßige Lint-Checks
